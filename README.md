# GoalTrack Pro

GoalTrack Pro is a web-based Goal Setting & Tracking Portal developed to help organizations digitally manage employee goals, approvals, quarterly progress tracking, and performance visibility in real time.

The platform replaces traditional manual tracking methods such as spreadsheets, emails, and offline review systems with a centralized and user-friendly digital solution.

# 📌 Problem Statement

Organizations that rely on manual or fragmented goal-tracking systems often struggle with alignment, visibility, accountability, and performance monitoring. Managers cannot effectively monitor employee progress, employees lack clarity on organizational goals, and HR teams face challenges during performance review cycles.

GoalTrack Pro addresses these issues by providing a structured digital platform that supports:
- Goal Creation & Submission
- Goal Approval Workflow
- Employee Progress Tracking
- Quarterly Check-ins
- Role-Based Access Control
- Real-Time Data Management

This project was developed as a solution for the AtomQuest Hackathon Problem Statement:
“In-House Goal Setting & Tracking Portal”.
